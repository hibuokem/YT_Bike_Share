# Data

The raw datasets are **not redistributed here**. They come from the original repository:

https://github.com/Gaelim/YT_bike_share

| File | Description |
|---|---|
| `bike_share_yr_0.csv` | Rental records, year 0 (2021) |
| `bike_share_yr_1.csv` | Rental records, year 1 (2022) |
| `cost_table.csv` | Cost data used to calculate profit |

To refresh or rebuild the report, download the files above and point the Power BI queries at them.
(The `.pbix` already contains an imported copy of the data, so it opens and works without them.)
